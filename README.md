# Willow & Peony

The website for [Willow & Peony](https://willowandpeony.co.nz) — a boutique
wedding & event florist in Auckland, New Zealand.

Built with Next.js (static export) and deployed to GitHub Pages via GitHub
Actions on every push to `main`.

- **Content**: `content/` (business facts, journal posts, redirects, legal)
- **Images**: originals in `assets/img-src/`, optimized WebP variants in
  `public/images/` (generated by `npm run images`)
- **SEO/AEO**: per-page metadata + canonical, JSON-LD (Florist, Service,
  Article, FAQPage, Breadcrumbs), `sitemap.xml`, `robots.txt`, `feed.xml`,
  `llms.txt`, legacy-URL redirect stubs
- **Workflow & conventions**: see [CLAUDE.md](CLAUDE.md)

```bash
npm install
npm run dev      # develop
npm run build    # static export to out/
npm run images   # regenerate image variants after adding photos
```
